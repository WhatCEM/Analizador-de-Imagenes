💡 Consejos

  • Para mejores resultados con documentos, usa imágenes de alta resolución
  • El modo "Extraer Texto" funciona como OCR para capturas de pantalla y documentos
  • Para código, sube capturas de tu IDE o editor de texto
  • Claude Opus 4.7 es el más potente; Haiku 4.5 es el más económico
  • También puedes usar la herramienta CLI: python analizador.py imagen.jpg --modo describir
